# BEE ĐIỆN LẠNH
Đồ án môn học Công Nghệ Phần Mềm
## Công nghệ sử dụng

- ASP.NET Core MVC

- C#

- Entity Framework Core

- SQL Server

- ASP.NET Core Identity

- Razor View

- Bootstrap

- Session

## Chức năng Customer

- Đăng ký

- Đăng nhập

- Xem sản phẩm

- Xem chi tiết sản phẩm

- Xem sản phẩm theo danh mục

- Thêm sản phẩm vào giỏ hàng

- Tăng/giảm số lượng

- Xóa sản phẩm khỏi giỏ hàng

## Chức năng Admin

- Đăng nhập

- Xem danh sách sản phẩm

- Thêm sản phẩm

- Sửa sản phẩm

- Xóa sản phẩm

- Upload hình ảnh sản phẩm

## Hướng dẫn chạy

1. Tải source code về máy.

2. Mở file BeeDienLanh.sln bằng Visual Studio.

3. Mở SQL Server Management Studio.

4. Chạy file Database/BeeDienLanh.sql để tạo cơ sở dữ liệu.

5. Sửa DefaultConnection trong appsettings.json phù hợp với SQL Server trên máy.

6. Build project.

7. Run project.
